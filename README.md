# Bike Sales Dashboard (Excel)

Interactive Excel dashboard analyzing bike purchase behavior using Pivot Tables, Pivot Charts, and Slicers.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers

## Insights
- Purchase trends by Age Group
- Income comparison by Gender
- Commute Distance vs Bike Purchases
- Interactive filtering by Marital Status, Region, Education, and Occupation
